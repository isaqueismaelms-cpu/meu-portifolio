
# Isaque — Portfólio Web

## Sobre o projeto

Este projeto é um portfólio pessoal desenvolvido para apresentar um pouco sobre mim, meus interesses, habilidades e objetivos.

O site foi criado com o objetivo de praticar desenvolvimento web e aplicar conhecimentos de HTML5, CSS3 e Bootstrap em um projeto próprio.

A ideia, os conteúdos e o esboço visual foram definidos por mim. Durante o desenvolvimento, utilizei o ChatGPT como ferramenta de apoio para organizar o código, solucionar problemas e aprimorar o visual e a estrutura das páginas.

## Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo
- CSS3 — estilização, layout, animações e responsividade
- Bootstrap 5 — apoio na construção de layouts responsivos e componentes
- Git e GitHub — versionamento e armazenamento do código
- Vercel — publicação e hospedagem do site

## Páginas do portfólio

- **Início:** apresentação inicial
- **Projetos:** apresentação da minha rotina e projetos relacionados ao futebol
- **Sobre mim:** informações pessoais, estudos, habilidades e objetivos
- **Hobbies:** futebol, games, programação e hardware
- **Contato:** formas de contato e informações sobre o desenvolvimento do projeto
